# 主角重设计：风格方案图规格（所有风格版本共用）

## 背景
英语学习游戏，玩家是小学 3–6 年级孩子。主角外观（职业、性别、衣服、武器）是孩子升级的主要动力，要有审美、有辨识度、让人想收集。
参考方向：地下城与勇士（DNF）的 Q 版角色——大头小身、剪影鲜明、武器夸张、职业一眼能认出。
现状问题：现有三个职业（剑士 / 神枪手 / 魔法师）轮廓太接近（同一副身体骨架，只是换了发型和手里的东西），男女差别也很小。**必须在剪影上就能分清 6 个角色。**

## 要画的 6 个角色（站立正面略带 3/4 的“立绘”）
| 职业 | 男 | 女 |
| --- | --- | --- |
| 剑士（近战，大剑） | 剑士·男 | 剑士·女 |
| 神枪手（远程，枪） | 神枪手·男 | 神枪手·女 |
| 魔法师（法杖 / 魔法书） | 魔法师·男 | 魔法师·女 |

职业气质：
- 剑士：热血、坚毅。重甲或长外套、披风、肩甲；武器是夸张的大剑（宽剑身、护手有造型）。
- 神枪手：帅气、灵动。牛仔 / 机械改造风；帽子或护目镜、腰带、枪套；武器是造型夸张的手枪或长枪，可有蒸汽 / 齿轮元素。
- 魔法师：聪明、神秘。长袍、斗篷、帽子或头饰；武器是带水晶 / 星星的法杖或浮空魔法书。

性别差异（要明显，不只是头发）：
- 男：肩宽、轮廓更方、短发或利落发型、裤装 / 长外套。
- 女：身形更纤细、腰线明显、长发 / 双马尾 / 发饰、裙装或短裙配长靴；服装设计本身也不同（不是同一套衣服换发型）。

## 通用要求
- 比例：Q 版，头身比由各风格自行决定，但 6 个角色用同一比例体系；身高 / 体型可有职业差异（剑士壮一点，法师细长一点）。
- 每个角色画：完整全身（头、躯干、双臂、双腿、鞋）+ 手持武器；表情开心，面向右前方（游戏里主角面向右）。
- 配色：每个职业有自己的主色（剑士：红 / 金；神枪手：蓝 / 铜；法师：紫 / 青），男女同职业共用主色但配色分配不同。
- 要能“升级后换更华丽的套装”：在每个角色旁再画一套 **“高阶套装”** 的变体（同角色换更华丽的衣服和武器：更多金边、发光、披风、翅膀 / 光环等），共 12 个形象（6 初始 + 6 高阶）。
- 线条和色彩：每个风格自定，但要统一；背景用纯色浅底，不要复杂场景。
- 不要画任何现成 IP 的角色，不要出现文字水印。

## 输出
- 一个 SVG 文件 `sheet.svg`：画布 1800×1000，上排 6 个初始角色，下排 6 个高阶套装，每个角色下面有中文名牌（如“剑士·男 · 初始”）。
- 另存一个 `preview.png`（用 Playwright/Chromium 把 sheet.svg 截图，2x 缩放）。**必须自己看过 preview.png 并迭代到满意**（比例、手脚是否连接正确、武器是否拿在手里、是否有明显的画错：断肢、重叠错位、颜色脏）。
- 写一个 `NOTES.md`（不超过 15 行）：风格名、头身比、线条 / 上色手法、6 个角色各一句设计亮点、如果采用本风格，做成游戏用的分部件（头 / 身 / 手 / 腿 / 武器）素材会遇到什么难点。
- 全部输出放在你被指定的目录。只写这个目录里的文件，不要改项目其它文件。

# 第三轮补充（用户反馈：A/B/C/D 全都“太暗黑了”，孩子们喜欢更可爱的风格）
这是对上面通用要求的**修订**，以本节为准：
- **去掉深色 / 黑色粗描边**：改用比填充色略深的同色系柔和描边（1–2px），或完全不描边靠色块和高光。整体亮度高、对比柔和，不要出现大面积深色（深紫、深蓝、暗红、黑）。
- **明亮糖果 / 粉彩配色**，主色明亮：剑士=珊瑚红 / 蜜橙 / 奶黄，神枪手=天蓝 / 薄荷 / 奶油，法师=薰衣草紫 / 粉 / 星光黄；高光和渐变柔和。
- **更小更圆更萌**：1.5–2 头身，大圆头，超大眼睛（有 2–3 个高光点），腮红，小嘴，圆手圆脚，没有尖角、尖刺、阴影沉重的盔甲。表情要甜、要笑，不要“酷”“痞”“凶”“邪魅”。
- **服装靠可爱主题区分职业**（不靠盔甲披风）：武器是“玩具感”的圆润大号造型（软糖剑、泡泡枪、星星魔杖、糖果法杖），配饰丰富（发夹、蝴蝶结、小翅膀、小背包、围巾、铃铛）。
- 脸仍要 6 个各不相同（脸型、眼型、眉、嘴、肤色至少 4 档、瞳色 6 种），每人一个**可爱**的标志（如：小虎牙、雀斑、酒窝、大蝴蝶结、眼镜、星星脸贴），缩到游戏大小（头宽约 90px）也能区分；男女服装设计本身不同；6 个角色的剪影要能一眼分开。
- 仍然是 6 个初始 + 6 个高阶（更华丽：闪粉、小翅膀、光环、更多饰品，但仍然明亮可爱，不暗黑）。
- 输出要求与上面相同（sheet.svg 1800×1000 + preview.png 2x；另加 faces.svg / faces.png 脸部特写 3×2 加 1:1 游戏尺寸对照条；NOTES.md ≤15 行；用 Playwright 截图并自己 Read 迭代至少 4 轮）。
- 不要画任何现成 IP 的角色或其明显变体。
