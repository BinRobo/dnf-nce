# 调研背景（给三个角色的共同简报）

## 项目
- 网页游戏《英语地下城》：借鉴 DNF（地下城与勇士）核心玩法，包装新概念英语第一册（144 课，单课课文 + 双课练习，72 个副本）的学习。
- 用户：小学 3–6 年级学生；目前家长自用（非商业），后续可能扩展。家长会严格审核设计。
- 运行环境：中国大陆，Windows 电脑浏览器为主（可能也有平板）；不能依赖谷歌服务。
- 已有素材：新概念第一册扫描课本（文字已录入 L1–L100 为 JSON）、每个单课的课文动画视频（已按字幕切出每句原声，可在游戏里播放）。

## 现状（第一版原型，已可玩）
- 技术：Phaser 3.90 + TypeScript + Vite，纯前端，IndexedDB 存档。代码在 /home/ubuntu/dnf/src。
- 玩法：城镇 → 选副本（每对课一个）→ 5 个房间答题（听音辨义 / 见义识词 / 拼写搓招 / 句型填空连词成句 / Boss 按课文顺序挖空）→ 结算评级 SSS–C、经验、装备掉落 → 背包换装强化 → 10 级转职；SM-2 间隔复习，每日深渊、怨念怪；疲劳值每天约 5 局。
- 画面：全部是程序绘制的简陋占位图（方块小人、史莱姆、哥布林），背景是渐变+三角形山。战斗表现只有：角色冲过去、一个白色弧线、几个粒子、伤害数字、屏幕震动。没有角色动画帧、没有技能特效、没有剧情、没有音效/BGM。
- 设计说明文档的要点见 /home/ubuntu/dnf/README.md 与 src/ 下代码；数值在 src/config.ts、src/systems/*.ts。
