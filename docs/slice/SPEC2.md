# 切片第 2 轮 · 剧情与美术补充规格

家长反馈：NPC 没作用没有引导、剧情太少只有打怪、没有等级差异。已确认的敌人命名体系（世界观《失落的台词》）：

- 最终反派：**缄默公爵 · 赫什**（Duke Hush，who=duke）。手下是“静默军团”，有 6 位“失语领主”各守一章。
- 小怪（按题型）：噤声蝙蝠（吞掉听到的声音）、迷镜史莱姆（让词义消失）、拆字哥布林（把单词拆成字母）、乱序魔像（打乱句子顺序）、空格小恶魔（把句子咬出空洞）、怨念雾灵（把忘掉的词偷回去）。
- 精英：L1-2 **吞音骑士 · 埃可**；L5-6 **名牌窃贼 · 诺曼**。
- Boss：L1-2 **吞声领主 · 帕顿**（who=boss_pardon，吞掉了街上的 Excuse me 和女士的手提包）；L5-6 **夺名迷雾 · 胡迷斯**（who=boss_whomist，偷走全班名字）。
- 第 1 章领主（尚未登场，可在台词里被提及）：**混名魔术师 · 维辛**。

## B. 主角武器外观（美术）

主角装备不同武器时，手里拿的武器要不同。参照现有 public/assets/art/chars/hero/weapon.svg（木剑）的画法、描边（#2B2A4A，外描 6、内描 2）、坐标约定（握柄中心为枢轴，剑尖朝上），以及 rig.json 中 weapon 的 px/py。

输出 public/assets/art/chars/hero/weapons/ 下：
| 文件 | 装备名 | 造型要点 |
|---|---|---|
| dagger.svg | 字母短剑 | 短刃，刃上刻字母 |
| longsword.svg | 单词长剑 | 比木剑长的钢剑 |
| staff.svg | 语法法杖 | 顶端紫色宝珠 |
| bow.svg | 发音之弓 | 竖持的弓（握把在枢轴处） |
| axe.svg | 句型战斧 | 单刃斧 |
| greatsword.svg | 拼写巨剑 | 宽大双手剑 |
| epic_sword.svg | 史诗·亚历山大的字典剑 | 金色、带蓝宝石，最华丽 |

并写 weapons.json：`{"dagger":{"file":"dagger.svg","px":..,"py":..}, ...}`（px,py = 握柄枢轴在该 SVG viewBox 中的位置）。尺寸与木剑同一量级（高 120–200）。在 public/assets/art/preview.html 里加一段“武器展示”：主角分别拿每把武器（按 rig 组装、手臂 -70°），Playwright 截图自查后汇报。只写 hero/weapons/ 和 preview.html。
