# 第 4 轮 C：后 5 个城镇街区的场景

美术风格、截图自查方法、“只写自己那一节的文件”，都同 docs/slice/ROUND4.md 开头的说明。

## 先看已有街区

已有街区的背景在 public/assets/art/bg/：
- 学园区：town_*、training_*
- 集市区：plaza_*、gate_*

画之前先截图看看这几张背景，新画的要和它们是同一套画风。

**格式要求：**
- 每屏由 3 层叠成：`<名>_far.svg`（远景天空/山）、`<名>_mid.svg`（中景建筑）、`<名>_ground.svg`（地面）。
- 每层都是 1280×720，根元素和已有文件一样：`viewBox="0 0 1280 720" width="1280" height="720" stroke-linejoin="round" stroke-linecap="round"`。
- **地面线固定**：角色脚底在 y = 484。ground 层从 y ≈ 470 往下画路面和人行道。mid 层的建筑底边落在 y ≈ 470。
- 每个街区有两屏，左右并排。第一屏右边缘和第二屏左边缘要能接上：地面、天际线高度、色调一致。
- 画面左右两端 x < 120、x > 1160 的地面上留空，那里会放路牌。
- 第二屏 x ≈ 640 附近留一块空地，程序会在那里放紫色的地下城传送门。
- 没有文字。

## 5 个街区（每个两屏 × 3 层 = 6 个文件）

| 街区 | 第一屏 | 第二屏 | 配色 / 气氛 |
|---|---|---|---|
| 山谷村 valley | valley_a：村口，田地、风车、木栅栏、远处青山 | valley_b：村中小路，几座带烟囱冒烟的小屋（其中一座窗户里能看到厨房灶台）、水井 | 田园，嫩绿 + 暖黄，上午 |
| 国王街 king | king_a：一排英式红砖联排房屋，门牌（用图形表示，不写字）、邮筒、路灯 | king_b：街角小公园、长椅、报亭、远处钟楼 | 城市午后，砖红 + 灰蓝 |
| 集市与车站 station | station_a：热闹的集市摊位，水果摊、帐篷、彩旗 | station_b：火车站站台、站房屋檐、远处一列卡通火车 | 明亮热闹，橙 + 天蓝 |
| 雪山邮局 snow | snow_a：雪山小镇，积雪屋顶、松树、红色邮局（门口有邮筒和信件箱） | snow_b：雪地小坡、雪人、远处滑雪缆车 | 冬日，白 + 冰蓝 + 一点红 |
| 剧院区 theatre | theatre_a：华丽的剧院正门，红幕布海报（图案）、灯泡招牌（只画灯泡不写字） | theatre_b：傍晚的剧院广场，喷泉、彩灯串、星星开始出现 | 傍晚，紫 + 金 + 深蓝 |

文件名举例：valley_a_far.svg、valley_a_mid.svg、valley_a_ground.svg、valley_b_far.svg……

## 分工

- 美术 K1：valley、king
- 美术 K2：station、snow
- 美术 K3：theatre

**预览：**写 public/assets/art/preview_r4c_<你的编号>.html。每个街区把两屏三层叠好、左右并排显示（即 2560×720 缩小显示），并在 y = 484 画一条红线，检查地面对齐。截图自查，至少迭代一轮。
